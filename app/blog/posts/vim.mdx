## Overview

juice.css is a lightweight, modern CSS framework that prioritizes developer experience and flexibility. It uses native CSS features like variables and custom properties for theming.

## Tech Stack

- **Language**: Pure CSS, PostCSS
- **Build**: PostCSS, npm
- **Theming**: CSS Custom Properties

## Key Features

- CSS variables for easy theming
- No JavaScript dependencies
- Small bundle size
- Compatible with any framework
- Extensible design system
