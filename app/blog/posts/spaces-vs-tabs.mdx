## Overview

hare is a personal AI agent platform that connects to multiple chat channels (Telegram, Discord, Slack) and provides extensible AI capabilities through a skill-based system.

## Tech Stack

- **Backend**: Cloudflare Workers, TypeScript, oRPC
- **Frontend**: React, Vite
- **AI**: Claude (Anthropic), Apple Foundation Models
- **Database**: PostgreSQL, Cloudflare D1
- **Deployment**: Cloudflare Workers & Pages

## Key Features

- Multi-channel support (Telegram, Discord, Slack)
- Device pairing for secure authentication
- Extensible skill system with workspace support
- Real-time WebSocket connections
- Admin UI for device management
