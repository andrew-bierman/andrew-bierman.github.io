## Overview

PackRat is an AI-powered travel planner that helps users create comprehensive packing lists for their trips. The app uses AI to analyze trip details and suggest appropriate items to pack.

## Tech Stack

- **Backend**: Node.js, TypeScript, Bun, Drizzle ORM
- **Frontend**: React Native, Expo, nativewindui
- **Database**: PostgreSQL (Neon)
- **AI**: Claude (Anthropic)
- **Deployment**: Docker, Railway

## Key Features

- AI-generated packing lists based on trip destination, duration, and activities
- Template system for common trip types
- Integration with maps for location-based suggestions
- Collaborative packing with family/friends
- Cross-platform (iOS, web)
