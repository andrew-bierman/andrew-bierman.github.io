## Overview

Prysm is a macOS application that brings AI capabilities directly to your desktop using Apple's on-device Foundation Models. Privacy-first design with local AI processing.

## Tech Stack

- **Language**: Swift, SwiftUI
- **AI**: Apple Foundation Models (AFM)
- **Platform**: macOS (App Store)
- **Build**: Xcode

## Key Features

- On-device AI (privacy-first)
- Native macOS integration
- Markdown rendering
- Context-aware suggestions
- Keyboard shortcuts
